# LinkedIn launch draft

Public project: https://jobs.richardhuang.dev

I’ve turned my Job Hunter project into a role-first, multi-user demo.

Enter a target job title and explore your own workspace — no sign-up needed.
The CV starts blank, so you can add your own details, experience and education,
then generate a downloadable PDF.

What the project demonstrates:

- Role-based onboarding, configurable job matching and application tracking.
- Separate visitor accounts, CVs and generated files.
- A Python/FastAPI backend, Next.js frontend, PostgreSQL and background workers.
- CV data entry, LaTeX PDF generation, export and deletion.
- Automated regression tests and a real browser journey across independent users.

The public demo uses fictional sample jobs and simulated fit scores. Each
workspace lasts 24 hours; export anything you want to keep. It is a project
demonstration, not a live recruitment service or a validated AI hiring model.
